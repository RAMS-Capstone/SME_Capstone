# data

`joint2_baseline_trace.csv` — `Gen3_throw_baseline.slx` 던지기 실행에서 기록한 관절 2 값이다(기본 출력, 89표본, 최대 간격 0.08 s).

열: `Time_s, TorqueBeforeLimit_Nm, TorqueApplied_Nm, ActualVelocity_rad_s, ActualPosition_rad, MechanicalPower_W`

1 ms 출력 기록(4,002표본)은 이 저장소에 없다. 민혁 PC의 `dense_output/`에 있으면 같은 폴더에 추가한다. 요구량 수치는 1 ms 기록 기준이 더 정확하다.
