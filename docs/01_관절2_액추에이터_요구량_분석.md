# 실제 던지기 baseline의 관절 2 액추에이터 요구량

> 저장소 메모: 본문에 나오는 `dense_output/`, `baseline_output.mat`, `입력_의존성_및_분석방법.md` 등 링크 파일은 이전 작업 환경(민혁 PC)에 있다. 이 저장소에는 `data/joint2_baseline_trace.csv`(기본 89표본)만 있다.

## 결론과 근거 범위

제공한 실제 궤적과 초기화 절차로 Gen3 baseline을 실행했다. **현재 검증용 PMSM 및 감속비 2는 이번 요구량을 충족하지 못한다.** 이것은 실제 Gen3 모터의 성능 판정이 아니라, 현재 검증용 모델의 전류·전압·감속비 설정에 대한 판정이다.

제한 전 토크, 제한 후 적용 토크, 실제 관절 속도를 공통 시간축으로 저장했다. 이번 실행에서는 ±100 N·m 포화가 발생하지 않아 제한 전후 토크가 같았다. 따라서 ±100 N·m를 요구 토크나 제조사 정격으로 사용하지 않았다.

1 ms 추가 출력 기록의 주요 수치는 피크 토크 약 **29.75 N·m**, 전체 4초 RMS 약 **15.64 N·m**, 최대 속도 약 **2.705 rad/s**, 최대 기계 출력 약 **68.08 W**, 최대 기계적 회생 출력 크기 약 **42.01 W**다. 이 기록은 4,002개 시각, 최대 간격 0.001 s다. 제조사 정격 선정에 필요한 여유율·열 검증·solver 수렴 검증까지 끝난 값은 아니다.

기본 실행도 별도 보존했다. 기본 기록은 89개 시각, 최대 간격 0.08 s로 피크 토크 29.676 N·m, 피크 정방향 출력 66.967 W였다. 추가 출력에서 이 값은 각각 29.748 N·m, 68.077 W가 되어 성긴 기록이 피크를 일부 놓쳤음을 확인했다. solver 종류·허용오차·MaxStep 및 물리·제어 파라미터는 유지하고 출력 시각 설정만 바꾸었다.

두 실행은 비트 단위로 같지는 않았다. 공통 55개 시각에서 최대 차이는 토크 0.01290 N·m, 속도 0.0006258 rad/s, 위치 0.00005034 rad, 출력 0.03690 W였다. 따라서 1e-7 수준의 엄격 일치 검사는 실패했음을 기록했다. 각 신호의 기본 기록 피크 대비 0.1%라는 명시적 비교 기준 안에는 들어가지만, 이것이 수치 오차에 대한 보증이나 solver 수렴 시험은 아니다. [기록 밀도 비교](./output_sampling_comparison.csv). 아래 본문은 추가 출력 기록을 기준으로 한다.

## 입력과 초기화

제공된 [실행 스크립트](../run_gen3_throw_decel05.m)와 [실제 입력 MAT](../baseline_input_decel.mat)을 기준으로 재현했다. MAT의 세 기준 신호는 0–4 s, 7×1×4001 timeseries이며 `t_release_plan=2.1 s`도 포함되어 있다. 모델 내부 Model Workspace의 `robotToTest`, `q0`, `dq0`를 사용했고, 초기 위치·속도는 입력 첫 표본과 일치했다. 임의 궤적이나 별도 `params.m`을 사용하지 않았다. 실행에 필요한 누락 입력은 발견되지 않았다.

제공 스크립트의 `t_throw_start=1.5 s`, 릴리스 2.1 s, 감속 종료 명령 2.6 s를 기준으로 구간을 구분했다. [의존성·로깅 위치·계산식·재현 절차](./입력_의존성_및_분석방법.md)에 상세히 기록했다.

## 구간별 요구량 — 1 ms 추가 출력 기록

RMS는 가변 시간 간격을 반영한 시간 가중 적분값이다. 토크는 관절축 기준이다. 아래 모든 구간에서 토크 포화 시간은 0이며 제한 전후 토크 지표가 같다.

| 구간 | 시간 s | 피크 토크 크기 N·m | RMS 토크 N·m | 최대 속도 크기 rad/s | 정방향 피크 출력 W | 역방향 피크 출력 W |
|---|---|---:|---:|---:|---:|---:|
| 준비 | 0–1.5 | 22.20 | 14.99 | 1.525 | 2.76 | -31.02 |
| 던지기, 릴리스까지 | 1.5–2.1 | 29.75 | 24.52 | 2.683 | 68.08 | 없음 |
| 감속 | 2.1–2.6 | 26.56 | 17.93 | 2.705 | 39.95 | -42.01 |
| 정지 명령 이후 | 2.6–4 | 9.30 | 9.27 | 0.003839 | 없음 | -0.0357 |
| 던지기+감속 | 1.5–2.6 | 29.75 | 21.77 | 2.705 | 68.08 | -42.01 |
| 전체 | 0–4 | 29.75 | 15.64 | 2.705 | 68.08 | -42.01 |

2.6 s 실제 속도는 약 0.003839 rad/s이며, 4 s에는 약 1.26e-8 rad/s다. 기본 기록에는 2.6 s 표본이 없어 인접한 성긴 기록을 선형 보간하면 0.01014 rad/s로 계산되지만, 추가 출력은 2.6 s의 값을 직접 기록한다. 정지 명령 시각에 실제 속도가 즉시 0이 되었다고 가정하지 않았다. 4 s의 유지 토크는 약 -9.265 N·m다. 속도가 거의 0이어서 기계 출력은 작지만, 토크와 전류 요구량은 사라지지 않는다.

전체 최대 위치 추종 오차는 약 0.01096 rad, 전체 RMS 속도 추종 오차는 약 0.01355 rad/s다. 토크 포화는 없지만 baseline에도 이 정도의 추종 오차가 있으며, 이 분석은 그 실제 응답에 대한 것이다.

정밀 수치: [구간별 지표](./dense_output/phase_metrics.csv), [추종 오차 문맥](./dense_output/joint2_tracking_context.csv).

## 토크와 속도의 동시 운전점

| 기준 | 시각 s | 적용 토크 N·m | 실제 속도 rad/s | 기계 출력 W |
|---|---:|---:|---:|---:|
| 전체 최대 토크 | 1.884 | +29.748 | +2.1116 | +62.82 |
| 전체 최대 속도 | 2.133 | +10.113 | +2.7052 | +27.36 |
| 전체 최대 정방향 출력 | 1.949 | +28.399 | +2.3972 | +68.08 |
| 전체 최대 회생 출력 크기 | 2.301 | -22.629 | +1.8562 | -42.01 |
| 준비 구간 최대 토크 | 0.958 | +22.203 | -1.2809 | -28.44 |

최대 토크와 최대 속도는 같은 시각에 발생하지 않는다. 위 표와 [전체 주요 동시 운전점](./dense_output/key_simultaneous_points.csv)은 실제 동일 시각의 곱을 사용한다. 준비 구간의 양의 토크·음의 속도는 모터가 로봇의 움직임을 제동하는 운전점이다.

## 기계적 회생 구간

추가 출력 기록에서 `tau_applied*omega_actual < -1e-6 W`인 연속 구간은 약 **0.4370–1.4736 s**, **2.1823–3.7691 s**다. 두 번째 구간의 대부분 에너지는 감속 중에 발생하며, 정지 명령 이후의 꼬리 구간 에너지는 매우 작다.

| 구간 | 양의 기계 에너지 J | 음의 기계 에너지 크기 J |
|---|---:|---:|
| 준비 | 0.599 | 16.547 |
| 던지기 | 22.588 | 0 |
| 감속 | 1.827 | 7.831 |
| 정지 명령 이후 | 0 | 0.00428 |
| 전체 | 25.013 | 24.383 |

이것은 관절 액추에이터 경계의 기계 에너지다. DC 버스 회생 전력, 배터리 회수 에너지 또는 제동 저항 용량과 같지 않다. 실제 효율, 동손·철손, 버스 전압, 회생 경로와 반복 주기가 추가로 필요하다. [회생 구간 기록](./dense_output/regenerative_intervals.csv).

## 현재 검증용 PMSM 평가

현재 값을 유지한 상태에서 `N=2`, `Kt=0.27 N·m/A`, iq 명령 제한 ±1 A이므로 정상상태 관절 토크 명령 범위는 **±0.54 N·m**다. 실제 역구동 상태에서의 절대 토크 안전 한계는 아니다.

| 항목 | 이번 요구량의 단순 환산 | 현재 검증 설정과 비교 |
|---|---|---|
| 피크 관절 토크 | 약 29.75 N·m | 0.54 N·m의 약 55배 |
| 전체 관절 RMS 토크 | 약 15.64 N·m | 정상상태 명령 범위를 크게 초과 |
| 피크 iq 환산값 | 약 55.09 A | iq 명령 제한 1 A 초과 |
| 전체 iq 시간 RMS 환산값 | 약 28.97 A | 실제 상전류 열 정격으로 직접 해석할 수 없음 |
| 던지기 iq 시간 RMS 환산값 | 약 45.41 A | 현재 설정으로 추종 불가 |
| 최대 모터 기계 속도 환산 | 약 5.410 rad/s | 속도만으로 구동 가능 판정 불가 |
| 준정상 q축 전압 최대 크기 | 약 1.548 V | 기존 q축 제한 1 V 초과 |
| 4 s 유지 iq 환산 | 약 -17.16 A | 정지 상태에서도 현재 토크 범위 초과 |

위 전류는 **요구 토크를 현재 검증 파라미터로 환산한 계산값이며 설정 변경 권고가 아니다.** 실제 PMSM을 Gen3에 연결하거나 이 전류를 인가한 시뮬레이션은 하지 않았다.

최대 속도 운전점에서는 필요한 토크가 약 10.113 N·m이므로 iq 환산값은 약 18.73 A다. 그때의 역기전력은 약 0.974 V이고 저항 전압까지 더한 준정상 q축 전압은 약 1.217 V다. 따라서 무부하 속도만 보아 "속도는 가능하다"고 판정하면 토크와 전압의 동시 요구를 놓친다.

전압 환산은 id=0, 이상적인 무손실 감속기 조건에서 `vq=Rs*iq+pole_pairs*N*omega_J*psi_f`를 썼다. `Lq*diq/dt`를 제외한 준정상 비교이며, 실제 인버터의 d/q 전압 원이나 동적 추종을 보장하지 않는다. 이 낙관적인 비교에서도 전류·토크 요구를 충족하지 못하므로 현재 구성의 부적합 결론은 분명하다. 현재 전류 제한·감속비·전압 제한을 확대하지 않았다.

## 확정된 근거와 추가 필요한 사양

| 근거가 있는 내용 | 아직 확정할 수 없는 내용 |
|---|---|
| 제공 궤적, 릴리스·감속 시각, Model Workspace 초기값 | 실물 로봇과 모델의 관성·마찰·부하 일치도 |
| 해당 baseline의 제한 전후 토크·실제 속도·기계 출력 | 실제 Gen3 제조사 모터·감속기 정격 |
| 현재 검증 파라미터와 전류·q축 전압 제한 | 실제 모터 Rs/Ld/Lq/자속/Kt와 온도·상전류 정의 |
| 이번 4초 및 각 구간의 토크 RMS | 반복 주기·휴지 시간·냉각 조건을 포함한 연속 열 정격 |
| 관절의 음의 기계 출력 구간 | 회생 효율·DC 버스 수용 능력·제동 저항 정격 |
| 현재 이상적 변환에서 요구량 미충족 | 실제 감속비·구동/역구동 효율·백래시·탄성·수명 |

추가로 encoder 방향/전기각, 실제 제어·PWM 주기, 전류·전압·속도 보호, 정격/피크 허용시간과 설계 여유가 필요하다. rotor spin 관성이 로봇 관성 자료에 포함되어 있는지도 확인해야 한다. 이번 baseline에는 별도 Motor_Mechanics나 rotor 관성을 추가하지 않았다. 누락된 rotor 관성·손실은 후속 단계에서 기계계와 모터 요구량에 한 번만 반영해야 한다.
