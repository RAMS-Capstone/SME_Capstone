# 관절 2 실제 사양 기반 PMSM·감속기 후보 비교 (통합 전 사전 계산)

작성: 2026-11-16 · 입력: 프로젝트의 `joint2_baseline_trace.csv` · 계산 코드: `candidate_sizing_j2.py`
**이 문서는 baseline 궤적에서 역산한 예상 계산이다. MATLAB/Simulink 실행 결과가 아니다.**

> **갱신(2026-11-16):** DC 링크 24 V, 24 V 권선(574741), 전류 명령 제한 두 사례(20.9 A / 10.4 A)로 결정했다. 1 ms 기록으로 재계산한 값은 `03_관절2_기준사양_결정.md`에 있으며, 그 문서가 본 문서의 A안(48 V) 파라미터를 대체한다.

## 1. 결론

1. **시뮬레이션 기준 후보로 A안을 제안한다: maxon EC-i 52 180 W, 48 V 권선(579165)과 Harmonic Drive CSG-17-100 조합, DC 링크 48 V.**
   - 모터 정격값(최대 속도 포함)을 공식 제품 페이지에서 모두 확인했다.
   - 효율 0.7 가정에서 모터 피크 토크가 정현파 환산 연속 토크의 약 0.98배다. 확인되지 않은 간헐 과부하 영역에 기대지 않아도 된다.
   - 전압 요구량은 약 15.3 V로, 48 V 버스의 벡터 한계 27.7 V보다 작다.
   - 감속기 반복 피크 토크 한계(70 N·m)는 요구 피크(29.75 N·m)의 약 2.35배다.
2. 비교 후보:
   - B안: maxon EC frameless DT 50 M(758031)과 CSG-17-100. 반사 관성이 가장 작고 로봇 관절형 구조다. 다만 최대 속도와 FOC 기준 데이터를 아직 확인하지 못했다.
   - C안: maxon EC-i 52 200 W 48 V(634043)와 CSG-17-80. 감속비를 낮춘 경우를 비교하는 조합이다.
3. 세 후보 모두 baseline 요구량(토크·속도·전압·감속기 평균 토크)을 계산상 충족한다. 다만 회전자 관성을 추가하면 관절 측에 **0.18–0.34 kg·m²**의 반사 관성(N²·J)이 생긴다. 그 가속 토크는 관절 환산 피크로 약 **1.7–3.3 N·m**로 추정된다. 무시할 수 있는 크기가 아니다.
4. **중요한 불일치가 있다.** Kinova 공식 사용자 가이드의 Gen3 대형 액추에이터 무부하 최대 속도는 **13 RPM(≈1.36 rad/s)**이다. 반면 baseline 던지기는 2번 관절에 **2.705 rad/s(≈25.8 RPM)**을 요구한다. 따라서 이 궤적은 실제 Gen3 액추에이터의 공개 속도 사양을 약 2배 넘는다. 위 후보들은 "Gen3를 재현한 부품"이 아니다. 이 궤적을 수행할 수 있는 가상의 상위 사양 액추에이터다.

## 2. 근거 범위와 데이터 주의

- 사용 CSV는 프로젝트에 올라온 **89표본(기본 실행, 최대 간격 0.08 s)** 버전이다. 1 ms 추가 출력 버전(약 4,002표본)은 현재 환경에 없다.
  - 피크 토크는 29.676 N·m(1 ms 기록 기준 29.748 N·m), 최대 속도는 2.702 rad/s(2.705 rad/s)다. 모터 측 피크 토크·전류는 약 0.25% 과소평가된다.
  - **관절 가속도는 속도를 수치 미분한 추정치다**(피크 9.57 rad/s², t≈2.39 s). 0.08 s 간격에서는 가속 피크가 평활화된다. 따라서 관성 토크는 과소평가되었을 가능성이 높다. 1 ms CSV로 재계산해야 한다.
  - 근접 중복 시각 2개는 병합한 뒤 미분했다.
- 회전자 관성을 추가하면 로봇 동역학과 CTC 응답이 바뀐다. 이 계산은 baseline 궤적이 그대로 유지된다고 가정한 개루프 역산이며, 통합 결과가 아니다.

## 4. 카탈로그 값을 dq 모델 값으로 변환

maxon 카탈로그 데이터는 블록 정류 기준이다. 기존 dq 모델은 진폭 불변 Park 변환을 쓴다(Te = 1.5·p·ψf·iq, iq는 상전류 진폭). 따라서 다음과 같이 변환한다.

| 변환 | 식 | 근거 |
|---|---|---|
| 정현파 토크 상수 | Kt,S = π/(2√3)·k_M,B ≈ 0.907·k_M,B | maxon academy 자료 |
| 연속 전류(진폭) | I_N,S = (2/√3)·I_N,B ≈ 1.155·I_N,B | 동손 동일 조건, maxon academy |
| 연속 토크 | M_N,S ≈ 1.05·M_N,B | maxon academy |
| 영구자석 자속 | ψf = Kt,S / (1.5·p) | dq 토크식 |
| 상저항 | Rs = R(상-상)/2 | **Y결선 가정** |
| 상인덕턴스 | Ld = Lq = L(상-상)/2 | **Y결선 + 비돌극 가정**(실제 Ld/Lq 미확인) |

검산: A안에서 Kt,S = 0.0834 N·m/A, ψf = 0.0834/12 = 6.95 mWb다. 블록 정류의 선간 역기전력 평균(3/π·√3·p·ψf)으로 되돌리면 k_M,B = 0.0919와 일치한다.

## 5. 후보별 요구량 계산

### 5.1 계산식

- 모터 속도: ωm = N·ωj
- 부하 토크(모터축): 구동(P = τj·ωj > 0)일 때 τj/(N·ηf), 회생(P < 0)일 때 τj·ηb/N, 정지 유지(|P| < 1 mW)일 때 보수적으로 τj/(N·ηf)
  - 회생 방향 효율 ηb는 구동 효율과 다를 수 있다. 그래서 **ηb = ηf(기준 가정)**와 **ηb = 1(모터 토크 상한)** 두 경우를 계산했다.
- 관성 토크(모터축): (Jm + J_WG)·N·αj. 감속기 앞단에 있으므로 효율을 곱하지 않는다.
- 전류: iq = Tm/Kt,S, id = 0
- 전압: vd = −ωe·Lq·iq, vq = Rs·iq + Lq·diq/dt + ωe·ψf. 비교 기준은 |v| ≤ Vdc/√3(SVPWM 선형 영역, 데드타임·소자 전압강하 무시)
- 감속기 평균 토크: T_av = (Σ|n|·t·|T|³ / Σ|n|·t)^(1/3)

### 5.3 해석

- **열**: 4 s 사이클을 쉬지 않고 반복한다고 가정해도 RMS 토크는 연속 토크의 28–49% 수준이다. 권선 열시정수(7–21.5 s)가 4 s보다 길어서 사이클 RMS 비교가 의미가 있다. 다만 실제 반복 주기·휴지 시간·하우징 방열 조건이 없으므로 이 결과를 열 정격 확정으로 보면 안 된다.
- **피크**: A안은 효율이 0.6까지 떨어지면 피크가 연속 토크를 약 14% 넘는다. EC-i는 철심 포화 때문에 정지 토크까지 낼 수 없다고 maxon이 명시한다. 따라서 허용 피크는 카탈로그의 간헐 운전 영역과 드라이브 피크 전류로 정해야 한다(**미확인**).
- **전압**: 최대 요구는 릴리스 직전(t≈2.08 s)에 발생하며, 대부분이 역기전력 ωe·ψf다. 155 °C 저항을 써도 증가는 0.1–1 V 수준이다. L·di/dt 항은 89표본에서 과소평가되었을 수 있다.
- **회생**: 관절 기계 회생 피크는 −42 W다. 모터 단자 전기 출력으로 환산하면 약 −30 W다(ηb = 0.7, 동손 포함 근사). 이 에너지는 DC 링크 커패시터·제동 저항·다른 관절이 흡수해야 한다. 이를 배터리 회수 에너지로 해석하지 않는다.
- **감속비 선택**: N = 80과 100 모두 감속기 한계 안이다. N = 100은 모터 토크를 줄이지만 속도와 반사 관성을 키운다. 같은 모터라면 반사 관성은 (100/80)² = 1.56배다.

| 전류 PI (예시) | Kp = ωc·L = 1.41 V/A, Ki = ωc·Rs = 892 V/(A·s), ωc = 2π·1 kHz | 모델링 가정(설계값) |
| Anti-windup 이득 | Kaw = Ki/Kp = Rs/L ≈ 631 s⁻¹ | 계산값(기존 Kaw = 52와 같은 규칙) |
| 마찰·백래시·비틀림 강성 | 미포함(강체) | 미확인 → 이후 단계 |

주의:
- 전류 명령 제한은 보호 기능이 아니다. 실제 과전류 보호·온도 보호는 별도로 구현하기 전까지 "없음"이다.
- 사례 1(5.30 A)에서는 η = 0.6일 때 요구 피크 6.1 A가 제한에 걸린다. 오히려 제한의 영향을 관찰하기에 적합한 시험이다.

## 7. 확정되지 않은 사항과 다음 단계

1. 1 ms CSV(`dense_output/joint2_baseline_trace.csv`)로 가속도와 L·di/dt를 재계산한다.
2. 드라이브 피크 전류 및 maxon 간헐 운전 영역을 정해 전류 명령 제한 사례 2를 확정한다.
3. CSG-17 효율 곡선, 최대 입력 속도, 입력 관성을 공식 카탈로그 PDF에서 수치로 확인한다.
4. DT 50 M의 최대 속도와 FOC 기준 데이터(설치 매뉴얼)를 확인한다.
5. 기존 Gen3 플랜트에 회전자 spin 관성이 포함되어 있는지 확인하고, 누락분만 한 번 반영한다.
6. 별도 모델 `Gen3_J2_PMSM_Actuator_A.slx`로 독립 시험(전압 벡터 한계·anti-windup 포함)을 한 뒤 2번 관절에만 통합한다.
